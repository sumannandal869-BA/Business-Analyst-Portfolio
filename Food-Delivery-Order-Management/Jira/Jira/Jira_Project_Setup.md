# Jira Project Setup

## Project Name
Food Delivery Management System

## Project Type
Software Development Project

## Project Methodology
Agile – Scrum

## Project Objective

The objective of this project is to develop a food delivery management system that allows customers to browse restaurants, view menus, add food items to the cart, place orders, make payments, and track their orders.

The system will also allow restaurants to manage menus and orders, while delivery partners can manage deliveries and update delivery status.

---

## Key Stakeholders

| Stakeholder | Responsibility |
|---|---|
| Customer | Browse food, place orders, make payments and track orders |
| Restaurant | Manage menu, receive and process orders |
| Delivery Partner | Accept deliveries and update delivery status |
| Admin | Manage users, restaurants, orders and system operations |
| Product Owner | Define product requirements and priorities |
| Business Analyst | Gather requirements, create user stories and coordinate with stakeholders |
| Development Team | Develop and implement the solution |
| QA Team | Test the application and validate requirements |

Example Jira Story
Story Title

Customer places a food order

User Story

As a customer, I want to place an order for selected food items so that I can receive my food from the restaurant.

Acceptance Criteria
Customer should be logged in before placing an order.
Customer should be able to add food items to the cart.
Customer should be able to review the cart before checkout.
Customer should be able to select a delivery address.
Customer should be able to select a payment method.
Order should be created successfully after successful payment.
Customer should receive an order confirmation.
Order status should initially be displayed as "Order Placed".

Definition of Done

A user story will be considered "Done" when:

Requirements are implemented.
Acceptance criteria are satisfied.
Development is completed.
Code review is completed.
QA testing is completed.
Defects related to the story are resolved.
UAT is completed where applicable.
Product Owner/business approval is received.
Documentation is updated where required.
